# One Word, One Username, One Reward

Entry for the make.fun bounty
[u-rusdyxbt-one-word-one-username-one-reward-1a191fae](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae).

`main.py` (pure Python standard library) writes the entrant's own make.fun username — one word, "soulbone" — and nothing else, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
